# Threads投稿ルール（2026-11-22改訂）

個人アカウント `@aus_physio_masa.therapist` のThreads投稿を作るときのルール。
このファイルが正本。投稿を作るたびに、ここに照らして確認する。

## 形式

- 短い質問＋糸井の強い個人の意見。
- リンク・ハッシュタグ・絵文字は入れない。
- 1投稿は1つの問いと1つの意見だけ。説明を長くしない。

## 改行（大事）

- 1文1行。ブロック間に空行を入れる。
- アプリ上では投稿文の `\n` が改行として表示される。
- 例（1行19文字以内に収めたもの）：
  - セラピストが職場を選ぶなら、
  - 何で決めますか？
  - 年収、働き方、人、分野。
  - 私は絶対、人派です。

## 1行19文字ルール（2026-11-22追加）

- スマホのThreadsは、1行の幅が約19文字。1行が19文字を超えると、画面で折り返されて読みにくくなる。
- 投稿文の表示される1行は、すべて19文字以内にする。句読点・「？」「…」も1文字として数える。
- 1文が19文字を超えそうなときは、文の意味を変えずに、自然な区切り（文節・フレーズの境目）で改行する。単語の途中で切らない。
- 改行だけではどうしても収まらないときだけ、文言を短くする。その場合は、どこをどう短くしたか記録する。
- 投稿を作るときは、公開前に全行の文字数を数えて確認する。19文字を超える行が1行でもあれば、出し直す。

- 例：2026-11-22に投稿した教科書の投稿は、1行目が23文字あって長く見えた。19文字ルールで書き直すとこうなる。
  - 理学療法士の皆さんに、
  - 素朴な疑問なんですけど、
  - AIが出てきて、まだ
  - 教科書で勉強する必要って
  - あると思いますか？
  - 最近、教科書を開く回数が
  - 減ってきた気がする…
  - ※この書き直しはルールの例。2026-11-22に実際に投稿した文面そのものは書き換えない。

## 問いかけと意見の文体

- 質問は敬語で書く。自分の意見は敬語じゃない、カジュアルな文体で書く。
- 文が硬すぎると返信が来ない。過去の伸びた投稿も、問いかけは敬語、意見はくだけた文体だった。

## 問いかけの言い方

- 「何だと思う？」は使わない。自分が答えを持っているように聞こえるため。
- 「教えてください」は入れない。2026-11-22の見直しで、不要と決めた。
- 意見を書かない投稿でも「教えてください」はつけない。質問そのものが呼びかけになる。

## 論点チェック（必ず通す）

- 全投稿が「それを聞いて何がわかるの？」に答えられること。
- 何がわかるのか（目的・学び）がはっきりしない質問は出さない。落とすか、言い換える。
- 論点がおかしい質問も出さない。例：AIと人間を単純に比べる問い（「AIより人間が優れている場所はどこですか？」は論点がおかしいため、「セラピストの仕事は、AIによってどう変わると思いますか？」に変えた）。
- 抽象的で意味のわからない意見は書かない。例：「考える時間が増えると思う」はダメ。
- 1つの投稿には、1つの「何がわかるか」を `intent` に書く。投稿文そのものには書かない。

## 意見の書き方（強く、個人的に）

弱い書き方はしない。「私はこうです」「私はこう思う」は弱い。

強い書き方を使う。

- 「圧倒的にこう思います」
- 「私は絶対こっち派です」
- 「私は○○が大事だと思います」

意見は、本当にそう思っているときにだけ書く。どっちも大事な二択（例：知識と考える力、肉体労働と知的労働、AIで調べるのと自分で読むの）には意見を書かない。意見なしで質問だけ出す。

## 重複チェック

- テーマが重なる投稿を2本出さない。見つけたら片方を別テーマに変える。
- 例：知識とコミュニケーション vs 知識と考える力 → 後者を技術とコミュニケーションに変えた。
- 例：教科書は必要か（2本）→ 片方を「教科書以外で使ってるもの」に変えた。
- 例：10年後のPT像（2本）→ 片方を「10年後に残ってほしい仕事」に変えた。
- 例：臨床の「なぜ」の聞き先（2本）→ 片方を「先輩への聞き方」に変えた。

  Kinapse用下書きにだけ置き、Kinapseアカウントができてから投稿する。

## テストのやり方

- 投稿は 19:00 Brisbane / 18:00 Japan。
- Threadsにスケジュール機能はない。毎回その場で承認を得て、即投稿する。
- 投稿から48時間後に判定する。ヒットは、ターゲット（日本のPT・PT学生）からの
  返信5件以上、またはターゲットフォロー3人以上。
- 見るのはインプレッションではなく、誰が返信したか。返信した人の背景も記録する。
- 2本連続でターゲット返信が2件未満なら、そのパターンは切る。
- 結果はアプリの `result48h` に記録する。数字は作らない。未記録は `null` のまま。
- 投稿して、改善して、投稿する、を繰り返してデータを溜める。

## 修正ポイント（2026-11-22、糸井のレビューによる変更履歴）

今週のテスト7本と改訂候補22本の全29本に、以下の修正を同じようにかけた。

1. **改行を入れた。** 全29本の投稿文を1文1行にした。改行は返信率に直結するため、投稿文の作り方として固定する。
2. **文体を分けた。** 質問は敬語、自分の意見は敬語じゃないカジュアルな文体にした。硬い文は返信が来ないため。
3. **「教えてください」を全廃した。** 意見あり・意見なしを問わず、投稿文に「教えてください」は入れない。以前のルール（意見がないときだけ使う）は廃止。
4. **「何だと思う？」は引き続き禁止。** 自分が答えを持っているように聞こえるため。
5. **論点チェックを導入した。** 全投稿が「それを聞いて何がわかるの？」に答えられること。通らないものは落とすか言い換える。例：
   - 「AIより人間が優れている場所はどこですか？」→ 論点がおかしいため「セラピストの仕事は、AIによってどう変わると思いますか？」に変更。
   - 「考える時間が増えると思う」→ 抽象的で意味がわからないため削除し、「客観的な評価は、人間よりAIの方ができそう」に変更。
   - 「AIがPTの代わりになるって、本気？」「AIに触診させたら、どうなる？」→ 未来系・非現実的なため、今回のテスト候補からは外した。
6. **意見の強さを上げた。** 「私はこうです」→「私は絶対、人派です」「私は圧倒的に、コミュニケーションだと思う」などに書き換えた。
7. **どっちも大事な二択には意見を書かない。** 知識と考える力、肉体労働と知的労働、AIで調べるのと自分で読むの、など。意見なしで質問だけ出す。
8. **重複を解消した。** 知識とコミュニケーション／知識と考える力、教科書の必要性（2本）、10年後のPT像（2本）、臨床の「なぜ」の聞き先（2本）は、片方を別テーマに変えた。
9. **具体性を上げた。** 「お金が十分にあっても」→「働かなくていいぐらいお金があっても、セラピストやりますか？」、「私は絶対、続けます」→「私は週2、3くらいはやりたいです」（具体的な数字の方がリアルなため）。
10. **「暗記と考える力」→「知識と考える力」に言い換えた。** 暗記という言葉より、知識の方が論点として正しいため。
11. **学生のAI利用の投稿は1文にした。** 「今の理学療法の学生さんって、AI使って勉強してるのかな？」の2文目は不要のため削除。
12. **各投稿に `intent`（何がわかるか）を書いた。** 投稿文そのものには書かず、アプリの `marketing.js` の `intent` フィールドに残す。
13. **1行19文字ルール（2026-11-22追加）。** 全29本の投稿文を、1行19文字以内になるよう改行し直した。文言は変えていない（改行だけ）。改行だけでは収まらない投稿はなかったため、短縮した文言はない。
